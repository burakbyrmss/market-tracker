# Roadmap

Each milestone ends in an exit check. Do not start a milestone until the previous one's exit check passes. Each version ships to the App Store and Google Play only after it passes the production gate in [Definition of Done](standards/definition-of-done.md).

Status values are `todo`, `in progress`, and `done`.

## V1.5: local portfolio

Detailed planning starts after V1 ships. Scope: transaction records on the device, holdings, and profit and loss through `domain/money`. Ends with the production gate.

## V2: accounts and cloud

Detailed planning starts after V1.5 ships. Scope: backend choice in its own ADR, authentication, sync of watchlists and the portfolio by our own IDs, and server-side price alerts. Ends with the production gate.
